# Data Source

## Dataset

This project uses the following publicly available synthetic dataset:

**Retail Store Inventory and Demand Forecasting**

- **Source:** Kaggle
- **Publisher:** Wavelet
- **License:** Apache License 2.0
- **Dataset:** https://www.kaggle.com/datasets/atomicd/retail-store-inventory-and-demand-forecasting/data

## About the Dataset

The dataset is synthetically generated for inventory and demand forecasting analysis.

It includes fields covering areas such as:

- Date
- Store ID
- Product ID
- Category
- Region
- Inventory Level
- Units Sold
- Units Ordered
- Price
- Discount
- Promotion
- Competitor Pricing
- Seasonality
- Demand

## How It Was Used

The dataset was transformed and modeled in Power BI to build an analytical solution focused on:

- Demand analysis
- Inventory monitoring
- ABC classification
- Forecasting
- Replenishment planning
- Reorder Point calculations
- Suggested Order Quantities

The dashboard design, analytical model, DAX calculations, business logic, and user experience were developed as part of this portfolio project.
